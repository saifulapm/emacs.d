* Inline emphasis & markup
You can mark text up inline:

- *bold*  (=*bold*=)
- /italic/  (=/italic/=)
- _underline_  (=_underline_=)
- +strikethrough+  (=+strike+=)
- =verbatim=  (literal, never interpreted)
- ~code~  (inline code)
- Super/subscripts: E = mc^{2},  H_{2}O,  x^{n} + y^{n}
  (rendered because =org-pretty-entities= is on; raw form is =mc^{2}=)

Tip: emphasis markers (=* / _ + = ~=) are visible in your setup; you can hide
them with =org-hide-emphasis-markers t= + =org-appear=.

* Entities, symbols & math
Org entities render to nice glyphs (=org-pretty-entities= is on):

- Arrows: \rightarrow \Rightarrow \leftrightarrow
- Greek:  \alpha \beta \gamma \lambda \Omega
- Misc:   \copy \trade \deg \plusmn \times \div \euro \hbar
- Spaces/dashes: en-dash \ndash em-dash \mdash

LaTeX fragments (preview with =C-c C-x C-l=; remove with =C-c C-x C-l= again):

- Inline:  \( a^2 + b^2 = c^2 \)   and the dollar form  $e^{i\pi} + 1 = 0$
- Display:
  \[
  \sum_{i=1}^{n} i = \frac{n(n+1)}{2}
  \]

* Blocks
** Source block (Babel) — named, with a variable and a result
#+name: square
#+begin_src emacs-lisp :var x=7 :results value
(* x x)
#+end_src

#+RESULTS: square
: 49
(=C-c C-c= inside the block runs it and writes/updates =#+RESULTS=.)

** Example block (verbatim, monospace)
#+begin_example

#+end_example

* Timestamps, repeaters & the diary
- Active (shows in agenda):   <2026-07-01 Wed>
- With time / range:          <2026-07-01 Wed 14:00-15:00>
- Inactive (no agenda):       [2026-07-01 Wed]
- Repeating:                  <2026-07-01 Wed +1w>   (weekly)
- Habit-style repeater:       <2026-07-01 Wed .+2d>  (2 days after you DONE it)
- Range between two dates:    <2026-07-01 Wed>--<2026-07-04 Sat>

Diary-style "sexp" timestamps (great for birthdays/holidays). In an agenda
file these show up automatically on the right day:
- Anniversary:  <%%(org-anniversary 1990 7 1)>
- Every Friday: <%%(org-class 2026 1 1 2026 12 31 5)>   (example pattern)

* Drawers
Property drawer (machine-readable key/values, hidden by org-tidy):
:PROPERTIES:
:GENRE:    reference
:RATING:   5
:END:

A custom named drawer (free-form, folds like any drawer):
:NOTES:
Anything can live in a custom drawer.  Press TAB on the :NOTES: line to fold.
:END:

* Dynamic blocks, macros & includes
** A macro
Defined in the file header as =#+macro: kbd=; use it like {{{kbd(C-c C-c)}}}
and it expands on export.

** Include another file (processed on export)
#+INCLUDE: "./org-cheatsheet.org::*One-page cheat sheet" :only-contents t
(In the buffer you just see this line; on export the section is pulled in.)

** Dynamic block (regenerates with C-c C-c) — a clock table example
#+BEGIN: clocktable :scope file :maxlevel 2
#+END:
(Your live column-view and clock dashboards are in ~/org/projects.org.)
